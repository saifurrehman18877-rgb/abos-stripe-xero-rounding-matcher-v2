# Stripe-Xero Rounding Matcher v2

SaaS businesses selling globally in multiple currencies suffer from tiny FX rounding discrepancies (often $0.01 to $0.05 per transaction) between Stripe's daily payouts and Xero's bank feeds. Bookkeepers waste hours manually creating 'bank fee' adjustments for hundreds of transactions so the accounts can reconcile and close the month. (Target customer: SaaS bookkeepers and finance managers)

## Running

Open index.html for the landing page; app.html is the working tool.
