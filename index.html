FAQ

How does RoundClose tell a rounding discrepancy from a real error?

It compares amounts in minor units within a small cent threshold and dates within a configurable tolerance window — matches within that band are flagged as rounding, everything else stays unmatched for your review.

Does this replace my Xero reconciliation workflow?

No — it prepares matched pairs and adjustment entries so you can import or post them in Xero in seconds instead of hand-building each line.

What if a transaction doesn't match on either side?

It's listed separately as unmatched Stripe or unmatched Xero so you can investigate real gaps instead of digging through hundreds of correct ones.
